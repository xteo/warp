MegaPrompt 01

Interactive GPU Ray Marcher

Medium ~250 lines

A real-time SDF scene explorer rendered entirely on GPU. Navigate a 3D scene of procedural objects — reflective silver, matte red, and emissive gold spheres, a metallic blue torus, and a green rounded box — using FPS-style keyboard controls. The ray marching kernel computes Phong lighting, soft shadows, ambient occlusion, and smooth-min blending in real time.

Key Features
  • SDF ray marching (128 steps)
  • Phong lighting + soft shadows
  • Smooth-min organic blending
  • Ambient occlusion
  • FPS camera (WASD + arrows)
  • Checkerboard ground plane
  • Headless PNG rendering
  • 30+ FPS at 1024x512
How to Run
Interactive 
uv run --with "pyglet>=2.0" --with matplotlib python prompts/mega_prompt_1/interactive_raymarch.py
Headless (single high-res PNG) 
uv run --with matplotlib python prompts/mega_prompt_1/interactive_raymarch.py --headless
Warp APIs Used
@wp.kernel @wp.func wp.tid() wp.vec3 wp.launch (2D) OpenGLRenderer
MegaPrompt 02

Real-time GPU Particle Fluid

Medium-Hard ~350 lines

An interactive 2D SPH fluid simulator with mouse-driven forces. Simulates 10,000 particles (adjustable 2k-30k at runtime) using Smoothed Particle Hydrodynamics with a cubic spline kernel. Uses wp.HashGrid for O(n) neighbor queries. Click to attract or repel particles, with velocity-based coloring from blue (slow) to red (fast).

Key Features
  • SPH with cubic spline kernel
  • wp.HashGrid neighbor queries
  • Mouse attract/repel forces
  • Dam-break initial config
  • Runtime particle count adjust
  • Velocity-based particle coloring
  • Weakly compressible EOS
  • Viscosity + gravity

MegaPrompt 03

Differentiable Scene Optimizer

Medium ~200 lines

Optimizes 3D sphere parameters to match a target image using differentiable rendering and automatic differentiation. A soft renderer computes per-pixel color from sphere parameters using front-to-back alpha compositing with sigmoid-based opacity. wp.Tape records the forward pass and backpropagates gradients, while warp.optim.Adam updates positions, radii, and colors — achieving 56x loss reduction in 150 steps.

Key Features
  • Differentiable soft renderer
  • wp.Tape auto-differentiation
  • Adam optimizer (warp.optim)
  • Front-to-back alpha compositing
  • 20 spheres optimized to target
  • Progress animation GIF output
  • Loss curve visualization
  • Headless-safe (no display)
How to Run
Default (500 steps) 
uv run --with matplotlib --with Pillow python prompts/mega_prompt_3/diffscene.py
Custom settings 
uv run --with matplotlib --with Pillow python prompts/mega_prompt_3/diffscene.py --steps 300 --num-spheres 30 --lr 0.005

MegaPrompt 04

GPU N-body Galaxy Simulator

Medium ~300 lines

A gravitational N-body galaxy simulator with 10,240 bodies. Uses tile-based force computation via wp.tile_load for ~2x speedup over naive O(N²) and CUDA graph capture (wp.ScopedCapture) to eliminate kernel launch overhead. Features leapfrog integration with softening, motion trails via circular buffer, and three presets: spiral galaxy, galaxy collision, and random cluster.

Key Features
  • Tile-based force (64-particle tiles)
  • CUDA graph capture
  • Leapfrog integration
  • Motion trails (circular buffer)
  • 3 presets (spiral/collision/cluster)
  • Velocity-mapped coloring
  • Benchmark: tile vs naive
  • Animated GIF output

MegaPrompt 05

Mini 2D Lattice Boltzmann CFD Solver

Hard ~400 lines

A GPU-accelerated D2Q9 Lattice Boltzmann fluid solver producing beautiful von Karman vortex streets. Implements BGK collision, Zou-He velocity inlet, zero-gradient outlet, and bounce-back boundaries. Simulates flow around a cylinder at Re=200 on an 800x200 grid, achieving ~179 MLUPS (million lattice updates per second) on GPU. Pure Python matching specialized CFD codes.

Key Features
  • D2Q9 Lattice Boltzmann method
  • BGK collision operator
  • Zou-He velocity inlet
  • Bounce-back boundaries
  • Von Karman vortex street
  • ~179 MLUPS on GPU
  • Vorticity + velocity viz
  • Configurable Reynolds number
